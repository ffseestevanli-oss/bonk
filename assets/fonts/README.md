# Bonk Pixel

`BonkPixel.ttf` is Bonk's own low-resolution interface font, drawn pixel by pixel in
[`tools/make_pixel_font.py`](../../tools/make_pixel_font.py) (rebuild it with
`python3 tools/make_pixel_font.py assets/fonts/BonkPixel.ttf`). The em is 6 pixels, so it's
pixel-exact at 6, 12 and 18 px.

It's part of Bonk! Model Prop-inator! and shares its license, GPL-3.0-or-later, with the font
exception: if you embed the font in a document, that doesn't by itself make the document GPL.
